# Kit spike screenshots

Written by `go run ./cmd/kitspike -shots <dir>`. Tags: `px1`/`px125` are the
platform pixel scale (1 / 1.25), `ui90`/`ui125` are the §3.0 UI scale on top of
px1, `dark`/`light` is the mode. `-open`/`-submenu`/`-closed-again` are the
menu's animation states.
