**Goal:** one host process (`fugue serve`) that owns the data directory and serves the Host API
over a private unix socket: peer-UID-authenticated Connect with `Hello` version negotiation,
client leases with a 10 s grace shutdown, `HostStatus` and `Shutdown`, with `host.json` and
`fugue.sock` discovery files that never mislead a client about who is alive. The
data-directory lock stays the only liveness authority.

**Architecture:** `internal/hostapi` (layer 5, ADR row already present) owns the transport:
socket path resolution, directory trust checks and binding, the per-connection peer-credential
check done during `Accept` (before any HTTP parsing), the h2c HTTP server, `host.json`, and
the Connect handlers that map proto types to domain types. `internal/app` (layer 4, row
already present) is the composition root for the host: it opens the store, builds the host
runtime (version negotiation, lease registry and grace timer on the injected clock, status
snapshot, draining flag, drain state machine) and owns the drain composition
(transport → store, in that order). `hostapi` imports `app` (declared edge); `app` never
imports `hostapi` — `app` defines the `HostTransport` interface (`Drain`), which
`*hostapi.Server` satisfies. `cmd/fugue` (layer 6, new) imports only `app`, `hostapi`,
`internal/config` and `internal/platform/...` (ADR directories table): it wires, handles
signals and prints. The drain never runs inside an RPC: the `Shutdown` RPC replies first and
the drain then runs asynchronously under `supervise.Go("app.host-drain")`; the RPC path, the
idle grace and the signal path converge on one runtime entry (`beginDrain`).

**Tech Stack:** Go stdlib (`net/http` with `http.Protocols` for unencrypted HTTP/2, `flag`,
`signal.NotifyContext`, `crypto/sha256`, `os.Lstat` for the socket path),
`connectrpc.com/connect` (already direct), `golang.org/x/sys` (already direct; its
`dependencies.md` row already names peer credentials for `internal/hostapi`; the
descriptor-based directory check needs only stdlib — `os.OpenFile` with
`syscall.O_DIRECTORY|syscall.O_NOFOLLOW`, `(*os.File).Stat` with `syscall.Stat_t.Uid`, and
`(*os.File).Chmod` — so that row is not widened),
`internal/platform/{clock,ids,errcode,redact,supervise}`,
`internal/config`, `internal/storage`, go-cmp, goleak. **No new third-party module** (Q-24 A).

**Spec:** base-doc `content/projects/dev-kit/core-harness/` at commit `04163f3`:
`host-api` §3 (process, socket, lifecycle, host.json), §4 (error contract: Connect code plus
typed detail with the public error code), §7 (principal and UID trust), §8 (Hello and
versioning); `cli` §2 (host start, lease lifecycle, version), §5.2 (exit codes), §7 (Host API
the client needs), §9 host rows CL-E01–CL-E04. Repository authority: ADR 0001
(`internal/hostapi`, `internal/app`, `cmd/fugue` rows; §6 amended per Q-24 A), roadmap F5.1
and stage A Q-02/A-01..A-08 (native only, Linux and macOS, CLI/TUI client), quality gates.

## Global Constraints

- The socket binds only inside the data directory or a user-private runtime directory — never
  TCP, never `0.0.0.0`. Every directory the socket lives in **and every directory fugue
  creates on the way to it** (on the fallback path both the per-user base `fugue-<uid>` and
  its `fugue/` child) passes a trust check before use: not a symlink, owned by this UID, mode
  exactly `0700` (created that way when absent; a directory this process owns is tightened
  to `0700`; a directory someone else owns fails closed). A directory fugue does not create
  (`XDG_RUNTIME_DIR` itself) must be owned by this UID and not be a symlink; its mode is left
  alone. Otherwise the owner of a parent could swap the child after the check. No
  world-accessible window at any point.
- The trust check runs on an open descriptor, never on a path twice: open each directory with
  `O_DIRECTORY|O_NOFOLLOW`, then `Fstat` and `Fchmod` that descriptor, so nothing can replace
  the directory between the check and the chmod. An owner the platform cannot report
  (`UIDKnown == false`) fails closed.
- The peer UID check runs on every connection during `Accept`. Mismatch **or unreadable
  credentials** reject the connection (fail closed) before any request is read.
- The data-directory lock decides who is alive: the store opens first (`app.StartHost`), and
  a second `fugue serve` fails typed without touching socket or `host.json`. A socket path is
  unlinked only when `Lstat` says it is a socket **and** a probe connect proves nobody
  answers it.
- `host.json` holds no secret; written atomically (temp file + rename) with mode `0600`
  after lock and bind, with versions read from the runtime (`Backend.Status` — one source,
  no duplicates in `ServerConfig`); removed first thing in a clean drain; never read back
  for host-side decisions.
- The vault stays locked on start; F5.1 adds no unlock RPC and logs nothing about vault
  contents. `client_kind` and `client_name` are informational; authorization is the UID check
  only, enforced in Go, never from client claims.
- Version strings parse as `v<N>` numerically; a malformed version is `invalid_argument`;
  negotiation picks the highest common version or fails with `unsupported_version` carrying
  the host's supported versions in its typed detail — never a silent fallback.
- The server sets **no** `ReadTimeout`, `ReadHeaderTimeout` or `IdleTimeout`: a leased
  connection must survive arbitrary idle periods, and the UID check is the access gate (a
  same-UID process is inside the accepted threat model, host-api §7). F5.2 revisits
  keep-alive when streams arrive.
- The runtime mutex is never held across the drain, across spawning the drain goroutine, or
  across any backend hook: the drain closes connections, whose close hooks re-enter
  `LeaseReleased`. A lease released while draining never re-arms the grace.
- `Shutdown` and the idle-grace drain follow one supervised stop path: the RPC replies
  first; the drain then runs asynchronously under `supervise.Go("app.host-drain")` and goes
  discovery files (`host.json`, socket) → listener → HTTP connections → store and lock last.
  No goroutine leaks (goleak in every new test package).
- Every goroutine starts through `supervise.Go` with a name and a stop path;
  `context.Context` is the first parameter and never stored in a struct (the runtime's
  long-lived context is captured at `StartHost` in closures, the same pattern as the
  F2.6a session actor); time (10 s grace, all timeouts) comes from `clock.Clock`; IDs from
  `ids.Generator`.
- Errors are `errcode` values using the nine existing codes **plus the new public
  `unsupported_version`** (Q-26 B); wrapped with `%w`; every Connect error carries a typed
  `ErrorDetail` proto detail with the public code (and, for `unsupported_version`, the
  host's supported versions). Hidden codes surface as a generic Connect `internal` error
  with no detail.
- `internal/hostapi` stays the only importer of generated proto code (`noprotoleak`); every
  new package has a `doc.go` (purpose, owner, allowed callers); non-test files ≤ 500 lines;
  `internal/hostapi` and `internal/app` meet the default 80 % coverage floor (they are not in
  `quality/coverage.json`, so no gate-file edit is needed).
- Tests: stdlib `testing` + go-cmp, `-race -shuffle=on`, fake clock, no `time.Sleep` or real
  waits, `goleak.VerifyTestMain` in every new package's `TestMain`.
- Each PR stays under roughly 600 changed non-test lines; stop and consult before exceeding
  it. Q-23 A splits the item so this holds (F5.1a, F5.1b, F5.1c).
- Commands: the `go test` lines in the steps name the packages and flags. Once PR #61
  (local resource limits) is on `main`, run them as
  `task test-pkg PKG=<packages> RUN=<regex>` and run the architecture tests as `task arch`;
  never run a bare `go test` then. Until it merges, run them with `GOMAXPROCS=2 GOFLAGS=-p=1`.

## Scope decisions made by this plan

These follow from the spec, the review and existing code; the reviewer may reject them.

1. **Peer credentials are a UID-only check with an injection seam.** The platform files give
   `peerCredentials(net.Conn) (PeerCredentials, error)` with `PeerCredentials{UID uint32}`
   (`SO_PEERCRED`/`GetsockoptUcred` on Linux, `LOCAL_PEERCRED`/`GetsockoptXucred` on macOS,
   both via `golang.org/x/sys/unix`; other platforms return an error — the Windows nightly
   build compiles a fail-closed stub). No test-backed consumer needs GID or PID, so they are
   not carried. The listener takes the function in its config (same pattern as
   `storage.LockOptions.CheckFilesystem`) so the reject path is testable without a second OS
   user. A real-socket test proves the syscall path returns this process's UID.
2. **Rejected connections die during `Accept`.** The checked listener closes the conn and
   continues; no request is parsed on a connection whose credentials failed. Rejections are
   counted; the count goes to a rate-limited `slog.Warn` (first occurrence, then every 10th)
   via the listener's `OnReject(count)` hook — the hook's consumer is cmd's logger, pinned by
   `TestListenerCountsRejections`.
3. **Socket path and directory trust.** `<dataDir>/fugue.sock` when it fits a conservative
   100-byte `sun_path` budget; otherwise `<RuntimeDir>/fugue/fugue-<hash12>.sock`, where
   `<hash12>` is the first 12 hex chars of sha256 of the canonical data dir. The trust check
   (Global Constraints) runs on whichever directory holds the socket — data dir included:
   `storage` only `MkdirAll`s it and its mode is not assumed — and, on the fallback path, on
   each directory from the runtime base down: `XDG_RUNTIME_DIR` (owner and not a symlink
   only), the per-user `fugue-<uid>` base, then `fugue/`. The open/stat/chmod probe is an
   injectable seam (`DirOps`) that works on descriptors, so tests cover symlink, foreign
   owner, unknown owner, wrong mode and a non-socket file at the socket path without
   privileges.
4. **Runtime directory comes from config.** `internal/config` (the only env reader) resolves
   the base at load time: `XDG_RUNTIME_DIR` when set, otherwise a per-user temp directory
   (`os.TempDir()`, which reads `TMPDIR`, is only called inside `config`) suffixed
   `fugue-<uid>`. `config.Config` gains one additive field `RuntimeDir`; `hostapi` appends
   `fugue/` and never reads the environment.
5. **Stale socket.** If the socket path exists, `Lstat` must say `ModeSocket` — a regular
   file (or anything else) is a typed failure and is never unlinked. For a real socket,
   probe-connect: a successful probe means something is serving — a contradiction (a live
   host would hold the lock) — so start fails typed and nothing is unlinked. A
   refused/invalid probe means a crashed host's leftover: unlink and bind. The lock remains
   the liveness authority; the probe is defence in depth so a live host's socket is never
   unlinked even if the lock is wrong.
6. **`host.json` fields:** `pid`, `started_at`, `socket_path`, `api_versions`,
   `host_version` (host-api §3; `host_version` supports the cli §2.3 upgrade UX). Versions
   come from the runtime's `Status` — `ServerConfig` carries no version fields (one source).
   A file left by a crashed host is overwritten on start — never read for host-side
   decisions. The client-side rule "connect and `Hello` before trusting it" is F7.1 and is
   noted in the file's doc comment.
7. **Lease semantics.** One successful `Hello` per connection creates the lease (negotiation
   first, then `LeaseAcquired`; if registration fails the connection stays lease-less and may
   retry `Hello`); a second `Hello` on a leased connection is a typed rejection; any other
   RPC before `Hello` is rejected; while draining, `Hello` and `HostStatus` callers get
   `unavailable`. `client_kind` `UNSPECIFIED` is `invalid_argument` (fail closed, no
   guessing). Kinds are informational (status counts); authorization is the UID check only.
   Lease release is detected by a close-notifying `net.Conn` wrapper — no goroutine per
   connection.
8. **Shutdown is a flag, not a dedup map.** `command_id` is mandatory: empty is
   `invalid_argument` even while draining. A `Shutdown` that finds the runtime active
   validates the ID, sets the `draining` flag, spawns the asynchronous drain and replies; the
   HTTP response is written before any connection is touched. Every later `Shutdown` gets the
   same reply from the flag — no persisted or in-memory receipt map.
9. **Grace goroutine.** Arming the grace creates the `clock.Timer` **and** a buffered
   `disarm` channel under the mutex (non-blocking), then — outside the mutex — starts one
   `supervise.Go(ctx, "app.host-grace", ...)` goroutine that selects on the timer, the disarm
   channel and the runtime's base context. At most one grace goroutine is live (arming is
   refused while a timer exists). Firing calls `beginDrain`; disarming (any new lease, or the
   drain itself) stops the timer and releases the goroutine; the base context cancels it at
   teardown. `TestLeaseZeroArmsGraceShutdown` and `TestNewLeaseInsideGraceCancelsShutdown`
   pin the behaviour; goleak pins the teardown.
10. **Drain composition lives in `app`.** `app.StartHost(ctx, deps)` opens the store (lock),
    builds the runtime from a `storage.HostIncarnation` **value** (the runtime never holds
    `*storage.Store`) and injects the drain closure `transport.Drain → store.Close` — the
    transport is `app.HostTransport`, an interface `*hostapi.Server` satisfies. `cmd/fugue`
    therefore imports only `app`, `hostapi`, `config` and `platform/...` per the ADR.
    `TestDrainClosesTheStoreAfterTheTransport` pins the order.
11. **`HostStatus` fields now:** `host_version`, `supported_api_versions` (ascending, most
    preferred last — the client derives the maximum from the list, so no separate
    `api_version`/`max_api_version` field), `incarnation_id`, `started_at`, `clients` by
    kind with a total (cli §7). Run/job/goal/verify counts arrive additively with F5.3+ — no
    placeholder fields. `HelloResponse.api_version` stays: it is the connection's negotiated
    version, a different thing from the host's list.
12. **`cmd/fugue`** uses stdlib `flag` (no CLI framework; F7.1 may revisit).
    `RunServe(ctx, out io.Writer, cfg config.Config, version string) int` is the testable
    entry point; `main.go` holds the printing and `context.Background`. Exit codes follow
    cli §5.2: SIGINT → **130**, SIGTERM and explicit cancellation → 0, startup failure → 1,
    usage error → 2 (pinned by `TestServeExitCodeForSignals` on the signal→code mapping).
    `host_version` is an ldflags-injectable variable defaulting to `dev`.
13. **Goleak discipline with `net/http`:** the serve loop runs under `supervise.Go
    ("hostapi.serve")`; the drain uses `http.Server.Shutdown`/`Close` so stdlib goroutines
    end; client test connections are closed before shutdown assertions; every new test
    package's `TestMain` calls `goleak.VerifyTestMain`.
14. **Client contract for F7.1 (recorded here, implemented there):** each client keeps one
    dedicated connection to the host for the life of the process — it does not share the
    connection with unrelated HTTP/2 traffic; its transport sets
    `StrictMaxConcurrentStreams` so a saturated connection surfaces an error instead of
    silently opening pooled connections; and it re-`Hello`s immediately after any redial,
    because every connection is a new lease and an un-`Hello`ed connection may call nothing
    else.

## Proto contract

All changes are additive within `fugue.host.v1`; `buf breaking` against `origin/main` passes.

`proto/fugue/host/v1/hello.proto` (modified):

```proto
// ClientKind says what kind of client owns the connection (docs: host-api §8,
// cli §7). Informational only: it is never a permission.
enum ClientKind {
  CLIENT_KIND_UNSPECIFIED = 0;
  CLIENT_KIND_TUI = 1;
  CLIENT_KIND_CLI = 2;
  CLIENT_KIND_APP = 3;
  CLIENT_KIND_APP_BACKGROUND = 4;
}

message HelloRequest {
  string client_name = 1;
  string client_version = 2;
  // supported_api_versions are API versions such as "v1", most preferred last.
  repeated string supported_api_versions = 3;
  ClientKind client_kind = 4;
}

message HelloResponse {
  // api_version is the version negotiated for this connection.
  string api_version = 1;
  // host_version is the running host's binary version, informational.
  string host_version = 2;
}
```

## Review Focus

1. **The credential window** — a connection is rejected during `Accept`, before any HTTP
   byte is read; a failed credential lookup is a rejection, never a pass. Pinned in Task 3
   (`TestPeerCredentialMismatchIsRejected`, `TestPeerCredentialUnavailableIsRejected`).
2. **Directory trust** — symlinked, foreign-owned, unknown-owner or wrongly-moded socket
   directories fail closed, at every level fugue creates (the runtime base included); the
   check and the chmod act on one open descriptor; a directory this process owns is
   tightened, never loosened; a non-socket file at the socket path is never unlinked. Pinned
   in Task 2 (`TestSocketDirectorySymlinkIsRejected`,
   `TestSocketDirectoryForeignOwnerIsRejected`, `TestSocketDirectoryUnknownOwnerFailsClosed`,
   `TestRuntimeBaseDirectoryForeignOwnerIsRejected`, `TestTrustCheckChmodsTheOpenedDescriptor`,
   `TestSocketDirectoryWrongModeIsTightened`, `TestRegularFileAtSocketPathIsNeverUnlinked`).
3. **The socket hand-off** — probe before unlink; a socket that answers is never removed,
   even when we hold the lock (that state is a typed failure). Pinned in Task 2
   (`TestStaleSocketIsReplacedWhenNoOneAnswers`, `TestLiveSocketIsNeverUnlinked`).
4. **A dying host cannot gain clients and cannot deadlock itself** — `host.json` and the
   socket go before the listener closes; the `Shutdown` RPC replies before the drain starts;
   the drain runs in its own supervised goroutine, never under the runtime mutex or inside
   the RPC. Pinned in Task 5 (`TestShutdownRPCRepliesBeforeDrain`,
   `TestHostJSONRemovedOnCleanDrain`, `TestDrainStopsServing`).
5. **Lease accounting and re-entrancy** — the 10 s grace is armed exactly when the last
   lease drops, cancelled by any new `Hello`, and never runs for foreground `fugue serve`;
   the runtime mutex is never held across the drain or a backend hook; a lease released
   during the drain never re-arms the grace. Pinned in Task 4
   (`TestLeaseZeroArmsGraceShutdown`, `TestNewLeaseInsideGraceCancelsShutdown`,
   `TestForegroundRuntimeNeverSelfShutsDown`,
   `TestLeaseReleasedDuringDrainDoesNotRearmGrace`).
6. **Shutdown re-entry** — a duplicate `Shutdown` while draining returns the same reply and
   starts nothing; an empty `command_id` is `invalid_argument`. Pinned in Task 4
   (`TestSecondShutdownWhileDrainingReturnsTheSameReply`,
   `TestShutdownEmptyCommandIDIsInvalidArgument`).
7. **Goleak under `net/http`** — `http.Server` spawns goroutines the repository does not
   start; the drain must actually end them. Every server test asserts a clean `goleak` exit.

// DirOps works on an open directory descriptor so the check and the chmod
// see the same directory. Open must use O_DIRECTORY|O_NOFOLLOW (a symlink
// fails to open); Stat and Chmod are fstat/fchmod on that descriptor.
type DirOps interface {
    Open(path string) (Dir, error)
}
type Dir interface {
    Stat() (DirStat, error)
    Chmod(mode fs.FileMode) error
    Close() error
}

}

  probe), `ErrSocketPathNotSocket`, `ErrSocketDirectoryUntrusted` (both
