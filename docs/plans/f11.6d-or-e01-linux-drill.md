# OR-E01 Linux Swarm Drill Runbook (F11.6d)

Owner-executed drill on Ubuntu Linux (`orchestration §14–15`, `OR-E01`).

## 1. Machine & Initial §7 Defaults

Record before starting:
- Machine: `uname -a`, `lscpu | grep -E 'Model name|CPU\(s\)'`, `free -h`
- Systemd user containment active: `systemctl --user status`
- Current §7 defaults under test:
  - `host.max_sessions`: `max(1, min(8, (RAM - 4 GiB) / 400 MiB))`
  - `host.per_account_sessions`: `6`
  - `host.heavy_commands`: `max(1, cores / 4)`
  - `host.prompt_pacing_min_seconds` / `max_seconds`: `10` / `15`
  - `teams.idle_detach_seconds`: `300`
  - `teamTaskCPUWeight`: `20` (`internal/app/vendor_service.go`)

## 2. Drill Workload (8 Agents)

1. Start `fugue serve` and the Gio desktop app on a real git repository.
2. Unlock the vault and propose + approve an **8-agent team** (1 lead + 2 team managers + 5 members across Claude, Codex, and `agy`, including tasks that invoke `fugue exclusive -- <build/test>`).
3. Keep all active tiers running simultaneously through at least one full task cycle + heavy command wave + idle-detach/wake cycle.

## 3. Measurements to Collect

Run in a separate terminal during peak 8-agent execution:

- **RAM (RSS & cgroup total):**
  ```sh
  free -m
  ps -eo pid,ppid,comm,rss:10 --sort=-rss | head -n 25
  systemd-cgtop -n 5 --depth=3
  ```
- **CPU & `CPUWeight` fairness:**
  ```sh
  mpstat 5 12
  pidstat -u -p ALL 5 12 | grep -E 'fugue|claude|codex|agy'
  ```
- **UI responsiveness (manual check while 8 agents stream):**
  - Switch between Chat / Inbox / Workspaces, scroll a long transcript, open a proposal or question card, and type in the composer.
  - Record any noticeable frame drop, input lag (>100 ms), or Gio stall.

## 4. Record & Retune §7 Defaults

| Metric | Observed Peak / Median | Retune Action (if any) |
| --- | --- | --- |
| Total RSS (8 agents + host + UI) | | Adjust `(RAM - 4 GiB) / 400 MiB` or `max_sessions` cap |
| Host + UI CPU / responsiveness | | Adjust `teamTaskCPUWeight`, `heavy_commands`, or `max_sessions` |
| Per-vendor 429 / pacing | | Adjust `prompt_pacing_min_seconds` / `max_seconds` or `per_account_sessions` |
| Idle detach / wake latency | | Adjust `teams.idle_detach_seconds` |
