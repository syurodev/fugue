API: New([]KnownValue, Options) *Detector; (*Detector).Find(string) []Finding;
Find(string) []Finding for detection without known values; Mask(string, []Finding) string.
KnownValue carries Value, Kind and optional env Key. Options carries AllowKeys,
AllowPaths. The current path is supplied per call through FindIn(text, path).
Rebuild by constructing and replacing a detector, retaining no caller-owned slices. Findings carry only Start, End, Kind and Key, never values.

Use stdlib Aho–Corasick with longest suffix outputs, merging overlapping known spans;
sparse sorted candidate lists are merged in byte order under source priority.
Fixed regexps are read-only after package initialization. Assignment parsing is line-based.
No new module, I/O, session state, placeholders, envelopes or reverse substitution.
